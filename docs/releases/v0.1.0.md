# v0.1.0

OpenMusic Meting API 的首个 Go 版本。独立 Go 模式支持网易云的歌曲、歌单、搜索、电台、歌词、播放和私人漫游。四平台兼容部署可以继续使用现有的 Node.js 管理后台、数据目录和 API Token。

- 可执行包支持 Linux、macOS 和 Windows 的 AMD64、ARM64。下载对应压缩包和 `SHA256SUMS`，校验后解压运行。
- Linux AMD64 和 ARM64 的 Go 容器归档支持直接执行 `docker load -i <归档文件>`。归档校验值保存在 `SHA256SUMS.docker`。
- GHCR 的 Go 镜像和 Node.js 兼容镜像可配合 `compose.release.yaml` 使用。发布工作流同时构建两种 Linux 架构。

如果从原 Node.js 版本升级，先备份完整数据目录和 Cookie 加密密钥。迁移文档包含并行测试、切流和回滚步骤。 [Node.js 到 Go 部署迁移指南](https://github.com/nova1751/openmusic-meting-api-go/blob/v0.1.0/docs/MIGRATE_NODE_TO_GO.md)
