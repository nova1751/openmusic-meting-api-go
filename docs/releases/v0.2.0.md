# v0.2.0

本版本为独立 Go 模式增加网易云专辑、部分 QQ 音乐查询与取链、旧版加密账号导入，以及可选的网站网关和精简账号管理页。

- 网站网关支持限定站点、歌单和专辑，并复用原有源站密钥；公网限流仍需由上游提供。
- 未配置 QQ 账号时会尝试免登录取链；实际可用性由 QQ 音乐返回的授权结果决定。
- 可导入旧版网易云和 QQ 账号数据；网易云账号支持扫码添加、启停，管理员支持双重验证。精简管理页仅允许通过受控反向代理访问。
- 独立 Go 模式还不具备原后台的 QQ 扫码、汽水、酷狗、多用户管理与监测等全部功能；QQ 账号取链和重新授权需要使用实际账号单独验证。需要完整功能时请继续使用 Node.js 兼容部署。
- 迁移前请备份数据及 Cookie 加密密钥，使用副本验证，确认需求后切换；回滚与权限要求见[迁移指南](../MIGRATE_NODE_TO_GO.md)。

Release 提供 Linux、macOS 和 Windows 的 AMD64/ARM64 可执行包及校验文件；GHCR 发布 Linux AMD64/ARM64 镜像。
