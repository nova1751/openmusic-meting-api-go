# 实现说明

## 服务结构

| 目录 | 职责 |
| --- | --- |
| `cmd/meting` | 加载配置，组装依赖，复用出站连接，捕获 SIGINT 和 SIGTERM 后有界关闭 |
| `internal/config` | 解析和验证环境变量及独立模式的账号 JSON |
| `internal/httpapi` | HTTP 路由、参数校验、签名入口、状态码映射、歌词格式和资源链接 |
| `internal/auth` | 独立模式的 Bearer、HMAC、断言时效及 nonce 防重放 |
| `internal/music` | 请求与响应类型、音质规则、账号选择、失效切换与 FM 冷却 |
| `internal/netease` | 网易云 API 请求、分页、字段转换、取链和歌词回退 |
| `internal/tencent` | QQ 曲库、取链、FM、MQTT 5 扫码与续期 |
| `internal/kugou` | 酷狗签名请求、曲库、KRC、取链和扫码 |
| `internal/qishui` | 汽水曲库、漫游、签名取链、音频解密和 Chromium 扫码 |
| `internal/migrate` | 读取旧版加密账号和令牌，保留旧数据格式 |
| `internal/nativeadmin` | 音源账号、Token、扫码、会话、双重验证和快照 |
| `internal/sitegateway` | 面向受限站点的歌单及媒体 ID 白名单 |
| `internal/legacy` | 兼容反代、就绪探测和内部授权请求 |
| `compat` | 固定上游版本的 Node.js 镜像与轻量授权入口 |

管理页使用 `go-qrcode` 在本机生成二维码，QQ 扫码使用 MQTT 5 WebSocket，汽水扫码使用 CDP。HTTP 客户端由入口注入，平台测试用实现 `http.RoundTripper` 的固定响应验证真实序列化行为。平台调用沿用请求的 context，取消、超时和关停信号可传到出站请求。Go 服务使用 `slog` 写结构化日志，记录路由、平台、错误码和状态。请求头、请求体、查询参数和上游错误文本不进入 Go 业务日志。

## 处理一条请求

1. `GET /api` 对缺省参数使用 `netease / playlist / 6907557348`。网易云 `search` 默认返回 30 首，显式分页的 `dj` 默认每页 100 条，`offset` 优先于 `page`，并验证限制和整数边界。
2. 独立 Go 模式直接校验签名。兼容部署中，网易云公共只读请求由 Go 处理，Go 先向 Node.js 内部入口提交原始 request-target。Node 调用原项目的授权中间件，验签后才返回这次调用应使用的显式 Cookie 或已有的网易云默认 Cookie。网易云 `url`、`fm`、房间私有接口与其他平台走原 Node.js 服务。
3. 网易云适配器在固定上游域名生成 API、WEAPI 或 EAPI 请求。WEAPI 使用随机请求密钥、两层 AES-CBC 和原协议的 RSA 封装。EAPI 以 API 路径、JSON、MD5 摘要组成明文，再按原协议使用 AES-ECB。签名密钥、服务 Token 和会员 Cookie 各自独立。
4. 歌单先查轨道 ID，再按 200 个一批请求歌曲信息。歌曲 ID 保留为 `json.Number` 或字符串，避免大整数在 float64 转换时丢失精度。电台显式分页只取一页，无分页时逐页合并、按节目 ID 去重，并处理限频重试。
5. 公共响应写回 JSON 数组、LRC 文本或 302。曲目里的播放、封面和歌词链接使用 URL 编码，保留 `quality`、`redirect` 和 FM 标记。电台搜索链接跳到 `type=dj`，歌单搜索链接跳到 `type=playlist`。房间私有入口沿用原版的原始资源 ID 和响应结构。

## 授权及账号细节

- 断言使用 base64url JSON，验证服务身份或 OpenMusic 账户格式。Go 按原协议用换行连接断言、HTTP 方法、原始路径与查询串、请求体 SHA-256，再用对应 Bearer Token 做 HMAC-SHA256。
- 独立模式检查 60 秒时差，用进程内存储原子登记 nonce，保留 120 秒，最多 100,000 条。程序化写请求在读取请求体前检查令牌和签名头，对请求体限制 1 MiB 和 10 秒。
- 兼容模式的两个路由分支共享 Node.js 防重放状态和配置。修改后台授权开关或删除令牌后，下一个请求即使用新状态。单个签名信任域部署一个授权进程。多副本要引入共享 nonce 存储。
- Go 禁止从公开路由访问内部授权入口，代理到 Node 的一般请求会删除内部密钥请求头。桥接请求使用独立的内部密钥。程序化响应统一发送 `Cache-Control: no-store, private`，媒体代理透传 `Range`、`Content-Range`、状态码和流式响应。
- 独立模式的公共取链以配置中的会员档位挑选账号，FM 播放优先使用满足该档位的 FM 账号，单次最多试四个账号。显式 Cookie 只用于当前请求。FM 失败账号冷却 30 秒，成功但无候选返回空数组，多账号尝试期间遇到请求取消会立即退出。
- 音质别名 `128`、`320`、`flac` 映射到标准、极高和无损。网易云按档位降级，响应以实际获得的音质为准。无响度字段时输出 `loudness: null`。
- 网易云普通歌词按时间戳合并翻译。结构化接口尝试 YRC，再调用 AMLL 精确 ID 的 TTML 接口。降级保留已有逐行歌词。AMLL 请求仅发送歌曲 ID。
- 使用旧数据目录时，账号凭证在内存中解密并按请求刷新；原文件中的启停、有效性及会员标记会影响后续请求。指定的旧令牌被撤销或更换时，请求立即失败。
- 可选网站网关通过来源密钥、Origin、集合白名单及集合中的媒体 ID 限制访问，边缘限流仍须由代理独立提供。

## 兼容差异与验证范围

- Go 独立模式的 `/` 和 `/test` 返回 JSON，兼容部署保留原文档页面和测试页面。
- 原版 README 描述网易云时长为秒，固定版本的实现与实测歌曲响应直接返回毫秒值。Go 保留实际响应值，避免既有调用方再次换算。
- 独立 JSON 账号文件启动时加载；旧 Node 数据目录按请求重新读取。FM 冷却存于内存。原生后台支持 Cookie、Token、用户角色、贡献账号、监测与 Webhook。交互式验证由官方页面完成，QQ 验证窗口接受管理员鼠标动作，汽水二次验证在隔离的 iframe 中运行。
- 兼容模式下，Go 处理的网易云只读请求的失败写入 Go 日志，成功请求仍经过原令牌鉴权。Node.js 的曲目请求成功计数和管理后台 API 日志只覆盖由 Node.js 执行的业务处理。
- 会员取链、私人漫游、扫码确认和汽水远程签名需要有效外部凭证，应在独立数据副本上验证后再切流。

- 汽水取链用随机的 30 分钟票据保存上游地址和播放材料，常规 JSON 返回代理 URL。音频端点使用相同的 Bearer 和签名鉴权，校验 CDN 域名后下载，按样本处理音频容器并支持 Range。解密路径使用有界内存和磁盘缓存。
- 管理页使用 Node 兼容的 AES-GCM 写入账号，随机 nonce 和账号 ID、平台绑定。导入支持原版 scrypt:v1 与历史密码哈希，首次登录后的 Go 密码记录独立保存。QQ 续期复用扫码 Cookie 的设备档案。

- QQ 普通歌词和逐字歌词分别请求。逐字歌词按协议解码 QRC、翻译和罗马音，在未取得
  QRC 时用数字歌曲 ID 或原请求 ID 查询 AMLL。酷狗取得 KRC 后以同一结构返回。
- 监测读取旧配置并后台复验活跃账号。QQ 异常时尝试原设备续期。Webhook 只在配置
  启用或管理员点测试时发送，域名解析后按允许的目标 IP 建连。API 访问记录批量写入
  数据目录，记录状态和时长，不记录明文 Cookie、Token 或完整查询串。

### 受控响应时间

Node v3.4.4 与 Go 使用同一台机器、相同的模拟 HTTPS 上游和八并发。模拟上游每次
请求延迟 30 ms。表内为三轮中位数，单位为毫秒。

| 接口 | Node p50 | Go p50 | Node p95 | Go p95 |
| --- | ---: | ---: | ---: | ---: |
| 网易云单曲 | 32.19 | 31.50 | 35.22 | 33.04 |
| 网易云 201 首歌单 | 101.56 | 97.62 | 113.73 | 113.54 |
| 网易云搜索 | 33.19 | 31.66 | 38.51 | 34.23 |
| QQ 搜索 | 33.56 | 31.51 | 39.69 | 34.21 |

测试末进程 RSS 约为 Node 235.2 MiB 和 Go 20.1 MiB，未启用 Chromium 或音频缓存。
真实接口的响应还取决于平台网络、账号状态和辅助服务，无固定加速百分比。
